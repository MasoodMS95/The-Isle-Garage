# Species artwork

22 original, hand-authored SVG silhouettes created for The Isle Garage. Each catalog species has its own file; unknown/custom names use unknown.svg. Coverage and dated roster sources are in docs/SPECIES.md. The shared allowlist and aliases are in lib/species-art.ts.

These stylized illustrations are not official game artwork, screenshots, skin previews, or scientific reconstructions. No external artwork was downloaded or traced. Related species share drawing primitives with species-specific differences in head, horns, crests, body or limb outlines.
